🧠 Praktik • muse.ai

Membuat Agent, langkahnya

  • 1. Buka muse.ai di browser / unduh aplikasi Muse (Android & iOS)
  • 2. Buat akun — ikuti verifikasi yang diminta
  • 3. Buat agent baru — beri nama, mis. "Asisten Matematika Pak Gun"
  • 4. Tulis instruksi peran: siapa dia, untuk siapa, gaya bahasa, aturan main
  • 5. Simpan — mulai pakai. Makin sering dipakai, makin nyambung

Tampilan menu bisa berubah seiring pembaruan — prinsipnya tetap sama.

Praktik • muse.ai

Contoh instruksi agent

"Kamu adalah asisten guru matematika SMP. Murid saya kelas 7–9, kemampuan heterogen. Setiap membuat soal: sertakan kunci berlangkah, tandai TP yang diukur, dan buatkan 3 level (penguatan–inti–pengayaan). Bahasa sederhana, contoh dari kehidupan sehari-hari. Jika saya tidak menyebut TP, tanyakan dulu."

Inilah "otak" agent Bapak/Ibu — semakin jelas instruksinya, semakin tepat hasilnya.

🐙 GitHub

Kenapa guru butuh GitHub?

  • Rumah digital untuk semua karya Bapak/Ibu: media, kuis, slide, modul
  • Tidak hilang walau HP rusak / laptop ganti — tersimpan di cloud
  • Bisa dibagikan lewat link ke murid & sejawat se-Indonesia
  • Gratis — dan menjadi fondasi untuk menerbitkan web sendiri
FKN
MGMP Matematika SMP
Praktik • GitHub

Membuat akun GitHub

  • 1. Buka github.com → Sign up
  • 2. Isi email, buat password, pilih username (mis. gunanto-matematika)
  • 3. Verifikasi email — klik link dari GitHub
  • 4. Selesaikan verifikasi "bukan robot" bila diminta
  • 5. Pilih paket Free — cukup untuk semua kebutuhan kita

Tips: pakai email aktif yang selalu dibuka — semua notifikasi ke sana.

GitHub Pages

Dari file menjadi website

  • GitHub Pages mengubah isi repository menjadi website gratis
  • Alamatnya: username.github.io/nama-repo
  • Cocok untuk kuis HTML, media interaktif, dan slide seperti ini
FKN
MGMP Matematika SMP
🚀 Praktik • GitHub Pages

Mengaktifkan Pages

  • 1. Di repository → tab Settings → Pages
  • 2. Source: Deploy from a branch
  • 3. Branch: main, folder: /(root) → Save
  • 4. Tunggu 1–2 menit — situs live di username.github.io/nama-repo

Syarat penting: file utama harus bernama index.html di folder root.

FKN
MGMP Matematika SMP
Praktik • GitHub Pages

Aturan main file

  • index.html di root = halaman yang dibuka pertama
  • Gambar taruh di folder assets/, panggil dengan path relatif
  • Nama file: huruf kecil, tanpa spasi (kuis-1.html, bukan "Kuis 1.HTML")
  • Satu repository = satu karya — rapi dan mudah dibagikan
