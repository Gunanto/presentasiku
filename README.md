## Menjalankan slide

Buka `index.html` di browser (Chrome/Edge) — **tidak butuh internet**, semua aset tertanam di satu file.

- Navigasi: panah ← → / spasi / klik kiri-kanan layar
- `F`: fullscreen • `Home`/`End`: slide pertama/terakhir
